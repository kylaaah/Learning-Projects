# Global E-Commerce Intelligence Pipeline

## 📖 Project Overview & Scenario
**The Problem:** A global retail enterprise (Superstore) was struggling to track their sales and identify why they were losing money. Their raw data was messy, inconsistent, and scattered across more than 51,000 international transactions.

**The Solution:** This project is an automated data pipeline and interactive business dashboard built to solve that problem. It automatically cleans and organizes the raw data, feeds it into a live Power BI dashboard, and successfully uncovered $447,000 in hidden profit leaks.

##  Tools & Technical Architecture
*   **Project Type:** End-to-End Data Pipeline & Exploratory Data Analysis.
*   **Python:** Used to build the automated data pipelines that collect, clean, transform, and organize the raw retail transactions.
*   **SQL (Queries, Joins, Aggregations):** Used to perform deep exploratory data analysis, create statistical summaries, and calculate exact profit losses.
*   **Microsoft Power BI:** Used to build the interactive "Command Center" dashboard that displays the cleaned data in real-time[.

##  Challenges & Solutions
*   **Challenge:** The raw global sales data was full of missing, inconsistent, and duplicate records. If used as-is, any business analysis would be completely inaccurate.
*   **Solution:** I conducted a rigorous issue investigation to catch these errors early. I then built automated data workflows that clean the data before it ever reaches the final reports.
*   **Challenge:** Ensuring the Power BI dashboard always had the most up-to-date and accurate numbers without manual updates.
*   **Solution:** I set up pipeline monitoring to ensure the data workflows operated reliably, creating a continuous supply of real-time data for the dashboard.

##  Impact & What I Learned
*   **Why It Matters:** This project gives the business a reliable, interactive way to view their global operations. More importantly, by analyzing operational discounting thresholds, the pipeline directly protected the company's bottom line by finding $447,000 in profit leaks.
*   **What I Learned:** I learned how to move beyond basic data cleaning to build robust, automated pipelines. I learned how to connect Python, SQL, and Power BI together into a single, continuous workflow that directly supports business decisions.
