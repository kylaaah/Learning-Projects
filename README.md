# Data Analytics Learning Portfolio 📊

A collection of foundational data analytics projects built to develop and showcase practical, hands-on skills in data manipulation, querying, and visualization. 

This repository serves as a log of my learning journey and contains projects utilizing **Excel, SQL, and Power BI**.

---

## 📂 Repository Structure

This repository is organized by the primary tool used for each project. Here is a brief overview of what you will find in each section:

###  1. Excel Projects
Focuses on data cleaning, exploration, and initial visualization using spreadsheets.
* **Topics covered:** Pivot Tables, VLOOKUP/XLOOKUP, Conditional Formatting, Power Query, and basic dashboard creation.

###  2. SQL Projects
Focuses on database querying, data extraction, and relational data management.
* **Topics covered:** Joins, Subqueries, CTEs (Common Table Expressions), Window Functions, and Aggregate Functions.

###  3. Power BI Projects
Focuses on business intelligence, data modeling, and creating interactive visual reports.
* **Topics covered:** DAX (Data Analysis Expressions), Data Modeling (Star Schema), Interactive Dashboards, and Data Storytelling.

---

##  How to Navigate This Repository

1. **Browse by Tool:** Click into the `Excel/`, `SQL/`, or `PowerBI/` folders above to see specific projects.
2. **Project READMEs:** Inside each project folder, you will find a dedicated README explaining the dataset, the business questions answered, and the key findings.
3. **Datasets:** Whenever possible (and non-confidential), the raw or cleaned datasets are included or linked so you can see the starting point of the analysis.
